# Rock_Paper_Scissor_Cut_Game_Python_Project
Simple Rock,Paper,Scissor Cut Game using Python Coding
Project Workflow:-
1. Input From User -(Rock,Paper,Scissor)
2. Computer Choice-(Computer will choose randomly not automatically)
3. Print The Result

Cases And Conditions=
A- Rock
Rock-Rock=tie
Rock-Paper=Paper wins
Rock-Scissor= Rock Wins
B-Paper
Paper-Paper=Tie
Paper-Rock=Paper Wins
Paper-Scissor=Scissor Wins
C-Scissor
Scissor-Scissor=Tie
Scissor-Paper=Scissor Wins
Scissor-Rock=Rock Wins
